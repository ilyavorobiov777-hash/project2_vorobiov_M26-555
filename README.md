# Примитивная база данных

Консольное приложение на Python, которое имитирует работу с базой данных:
создание и удаление таблиц, добавление, чтение, изменение и удаление записей.
Описание таблиц хранится в `db_meta.json`, данные каждой таблицы в `data/<имя>.json`.

## Установка

```bash
make install
```

## Запуск

```bash
make run
```

или

```bash
uv run database
```

## Управление таблицами

Команды:

- `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` - создать таблицу
- `list_tables` - показать список всех таблиц
- `drop_table <имя_таблицы>` - удалить таблицу
- `help` - справочная информация
- `exit` - выход из программы

Поддерживаемые типы данных: `int`, `str`, `bool`.
Столбец `ID:int` добавляется автоматически.

Пример:

```
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.
```

## CRUD-операции

Команды:

- `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` - создать запись
- `select from <имя_таблицы>` - прочитать все записи
- `select from <имя_таблицы> where <столбец> = <значение>` - прочитать записи по условию
- `update <имя_таблицы> set <столбец> = <новое_значение> where <столбец> = <значение>` - обновить запись
- `delete from <имя_таблицы> where <столбец> = <значение>` - удалить запись
- `info <имя_таблицы>` - вывести информацию о таблице

Правила ввода значений:

- строки пишутся в двойных кавычках: `"Sergei"`
- числа без кавычек: `28`
- логические значения: `true` или `false`
- `ID` вводить не нужно, он назначается автоматически

Пример:

```
>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".

>>>Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+

>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.

>>>Введите команду: delete from users where ID = 1
Запись с ID=1 успешно удалена из таблицы "users".

>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

## Обработка ошибок, подтверждение действий и кэш

Дополнительное поведение вынесено в декораторы (`src/primitive_db/decorators.py`):

- `handle_db_errors` - перехватывает ошибки (`FileNotFoundError`, `KeyError`, `ValueError` и другие) и печатает понятное сообщение, программа при этом не завершается
- `confirm_action` - перед опасной операцией спрашивает подтверждение; используется для `drop_table` и `delete`
- `log_time` - печатает время выполнения функции; используется для `insert` и `select`
- `create_cacher` - замыкание с кэшем для `select`: одинаковый запрос к тем же данным не пересчитывается. Данные таблицы входят в ключ кэша, поэтому после `insert`, `update` и `delete` результат всегда актуальный

Пример:

```
>>>Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записи"? [y/n]: y
Запись с ID=1 успешно удалена из таблицы "users".

>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: n
Операция отменена.

>>>Введите команду: insert into users values (Ivan, 40, true)
Ошибка валидации: Ivan. Строки нужно писать в кавычках.
```
